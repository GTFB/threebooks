# Протокол проверки теории Simulizm

> **МОДЕЛЬ:** карта проверки. D.A.S.H.A. дала текст — **ты** проверяешь телом, не верой в AI.

Карту можно любить. Полезно только то, что проходит через тело. Ниже — шесть рабочих шагов. Без них любая глава остаётся красивым файлом.

## 1. Соматическая телеметрия (90 секунд)

1. Сядь. Стопы на полу.
2. Назови вслух один тезис из главы (MODEL или HYPOTHESIS).
3. Девяносто секунд — только дыхание и ощущения: где сжатие, тепло, пульс, зевота.
4. **ФАКТ (интероцепция):** тело реагирует до «согласия» ума. Запиши: расширение или сжатие.

## 2. QoS-аудит (24 часа)

| Интервал | Вопрос | Метрика |
|----------|--------|---------|
| Утро | Куда ушёл первый час внимания? | QoS после vs до |
| День | После контакта с X — рост или падение? | 1–5 по телу |
| Вечер | Сколько % трафика — чужой скрипт (новости, сравнение)? | % на глаз |

Один день. Не идеальная таблица навсегда — срез.

## 3. Prediction error

1. Сформулируй **если верно → тогда увижу** (одно наблюдаемое за неделю).
2. Через семь дней — да / нет / неоднозначно.
3. Неоднозначно ≠ «модель доказана». Уточни гипотезу или понизь уверенность.

## 4. Семейный changelog (Legacy)

1. Три повторяющихся сценария в роду (деньги, пары, болезнь).
2. Интервал примерно 50–75 лет — **ГИПОТЕЗА** цикла, не астрология.
3. Проверка: ты прерываешь сценарий **одним** действием (не лекцией родне) — что в теле?

## 5. Слои — не смешивать

| Увидел в теле | Статус вывода |
|---------------|---------------|
| Повторяемая реакция | ФАКТ (для тебя) |
| Чужой рассказ NDE / поле | WITNESS — не доказательство космологии |
| «Runtime устроен так» | MODEL / HYPOTHESIS |
| «1812 = wipe» | ТЕОРИЯ — только с контрапунктом |

Смешал слои — получил догму. Держи таблицу рядом с любой спорной главой.

## 6. Антивирус #3 (проверка на догму)

Если текст главы вызывает **только** желание доказывать другим — пауза. Вернись к §0.4. Модель полезна, пока проверяется. Когда становится догмой — отложи.
