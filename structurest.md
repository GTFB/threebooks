# Repository structure

Reading order: Simulism (`sim/`) → ROOT (`root/`) → COREX (`corex/`).

```
threebooks/
  package.json
  wrangler.toml
  .gitignore
  scripts/
    build-reader.ts
  public/                        # generated by bun run build (not committed)
  sim/                           # Симулизм
    manifest.ru.json
    0/ … 25/, appendix-hypotheses/, axioms/, epilog/, verification-protocol/
  root/                          # ROOT
    manifest.ru.json
    01-root-access/ … 53-bug-map/
  corex/                         # COREX
    manifest.ru.json
    01-corex-access/ … 21-game-character-sheet/
```

## Rules

- Chapter dirs contain `ru.mdx`.
- Manifests list section/chapter order.
- `bun run build` regenerates `public/` for Cloudflare Workers.
- `bun run deploy` builds and deploys with `CLOUDFLARE_API_TOKEN`.
- PWA: `public/sw.js` precaches all chapters on first visit; `manifest.webmanifest` + `icon.svg` for install.
